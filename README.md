# D2D Ai

Build the foundation of a premium AI-powered productivity app called "Project Nova" (temporary name). This is NOT just a to-do app. It will grow into an AI Life Assistant for students first, then professionals. Design the project to be modular and scalable so new features can be added easily. Tech Stack: - React + TypeScript - Tailwind CSS - Mobile-first responsive design - Clean component-based architecture - Prepare for Supabase authentication and database integration - Dark mode and light mode support Design Style: - Modern, premium, minimal - Rounded cards - Smooth animations - Plenty of spacing - Beautiful typography - Apple + Notion + Material Design inspired - No bright or cluttered UI Create these screens: 1. Splash Screen - App logo placeholder - App name - Tagline: "Organize. Focus. Achieve." 2. Onboarding (3 screens) - Welcome - AI-powered organization - Get Started 3. Authentication - Sign In - Sign Up - Forgot Password - Social login placeholders 4. Home Dashboard Include placeholder cards only (no functionality yet): - Today's Tasks - Calendar - Notes - Thought Inbox - Reminders - Study Progress - AI Daily Brief (Coming Soon) - PDF Library (Coming Soon) Add a floating "Quick Capture" button that will later allow users to instantly add: - Task - Note - Thought - Reminder - Calendar Event Bottom Navigation: - Home - Tasks - Calendar - AI - Profile Profile Screen: - User profile - Dark/Light mode toggle - Settings - About - Version Architecture Requirements: - Organize code by feature, not by file type. - Create reusable UI components. - Prepare folders/modules for: - Authentication - Dashboard - Tasks - Calendar - Notes - Thought Inbox - Reminders - PDF Library - Analytics - AI Assistant - Settings - Keep the project scalable and maintainable. Do not implement business logic yet. Focus on creating a beautiful, production-ready foundation with navigation, reusable components, placeholder screens, and excellent UX. This should feel like the first version of a real startup product, not a simple demo.
